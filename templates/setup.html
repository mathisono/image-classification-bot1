1. Mount a Windows SMB share

This page is available only from the local machine. Credentials are written to ~/.smbcredentials/image-librarian.cred with mode 0600 and are never displayed again.

The web service must be allowed to run sudo -n mkdir and sudo -n mount -t cifs. If that permission is unavailable, the page reports the terminal setup requirement instead of hanging.
